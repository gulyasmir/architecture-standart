# FURPS+ таблица



| Код | Требования                                                                                                         | Комментарий                                                                                                 |
| ------ | ---------------------------------------------------------------------------------------------------------------------------- | ---------------------------------------------------------------------------------------------------------------------- |
| F      | Функциональные (Functionality)                                                                                 |                                                                                                                        |
|        | Клиент может подать заявку на депозит через интернет-банк                   | Указывается сумма, срок и счёт списания                                               |
|        | Клиент может подать заявку на депозит через сайт                                    | Указывается ФИО и номер телефона                                                           |
|        | Менеджер кол-центра получает заявку и связывается с клиентом             | Интеграция сайта с системой кол-центра                                                |
|        | Клиент получает СМС после подтверждения ставки и открытия депозита | Требуется интеграция с СМС-шлюзом                                                         |
|        | Персонализированные ставки отображаются в интернет-банке                  | На основе данных клиента (пока ручной расчёт)                                     |
|        | Менеджер бэк-офиса подтверждает заявку через АБС                                   | Ручной процесс, как в текущей модели                                                     |
| U      | Удобство использования (Usability)                                                                      |                                                                                                                        |
|        | Интерфейс соответствует брендбуку банка                                                  | Используется единая дизайн-система                                                      |
|        | Удобный и интуитивный пользовательский путь                                           | Максимально простой UX для клиента                                                         |
| R      | Надёжность (Reliability)                                                                                           |                                                                                                                        |
|        | Доступность интернет-банка 99,9%                                                                     | Требует работы с резервным ЦОД и масштабируемости                           |
|        | Работа всех систем 24/7                                                                                      | Требование бизнеса, критично при росте трафика                                 |
|        | АБС не должна перегружаться из-за новых интеграций                                | Следует изолировать новые процессы от АБС                                          |
| P      | Производительность (Performance)                                                                           |                                                                                                                        |
|        | Быстрый отклик (< 1 сек) при любых действиях пользователя                       | Текущие справочники загружаются медленно — надо оптимизировать |
|        | Горизонтальное масштабирование ИБ и распределение нагрузки              | Актуально в перспективе роста онлайн-клиентов                                  |
| S      | Поддерживаемость (Supportability)                                                                            |                                                                                                                        |
|        | Используются технологии, уже освоенные внутри банка                             | MS SQL, Oracle, .NET, React, PL/SQL                                                                                    |
|        | Возможность расширения под другие продукты (например, кредиты)          | Заложить модульность и масштабируемость                                            |
|        | Создание технической документации по API и архитектуре                          | Важно для поддержки и развития                                                               |
| +R     | + Ограничения (Restrictions)                                                                                      |                                                                                                                        |
|        | Обязательная идентификация новых клиентов в отделении                        | Требование законодательства                                                                  |
|        | Интернет-банк не поддерживает Kafka                                                                | Нельзя использовать в MVP, только на будущее                                         |
|        | АБС масштабируется только вертикально                                                      | Важно для проектирования архитектуры интеграции                             |
|        | СМС-модуль завязан на ядро подрядчика                                                        | Лучше реализовать СМС отдельно силами ИТ-отдела                               |
|        | Данные о ставках ведутся вручную в Excel                                                        | Требуется централизованное хранение, возможно в АБС                       |
