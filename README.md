# architecture-standart

В данной работе приведен пример цифровой трансформации банка, в частности расширение функционала онлайн каналов для привлечения клиентов.

Основная категория клиентов банка — люди старшего возраста, которые предпочитают офлайн-обслуживание. Именно поэтому онлайн-каналы  развиты так слабо.

Чтобы развиваться дальше, компании нужно привлечь больше клиентов, которые относятся к более молодым категориям. Поэтому сейчас в приоритете развитие онлайн-каналов для привлечения и обслуживания клиентов.
